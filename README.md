# Vier op een rij in Angular

Deze repository bevat een eenvoudige Angular 17 toepassing waarmee je het spel *Vier op een rij* lokaal kunt spelen. Het bord is volledig interactief en bevat visuele aanwijzingen voor de huidige speler, een highlight voor de laatste zet en een knop om snel opnieuw te beginnen.

## Project starten

1. Installeer de afhankelijkheden:

   ```bash
   npm install
   ```

2. Start de ontwikkelserver:

   ```bash
   npm start
   ```

   De applicatie is daarna beschikbaar op <http://localhost:4200>.

## Belangrijkste features

- Volledig interactieve *Vier op een rij*-logica met overwinning- en gelijkspel-detectie.
- Standalone Angular component met `signal`s voor eenvoudige state management.
- Toegankelijke bediening via muis en toetsenbord.
- Moderne styling met previews van de volgende schijf voor meer spelplezier.
